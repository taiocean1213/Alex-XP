# Codebase Summary

This repository contains Rust examples focused on ownership, borrowing, lifetimes, recursion, and macro-based "class/trait" automation. Below is a short description of each file and the main symbols to inspect.

## Top-level files
- [README.md](README.md) — existing repository README.
